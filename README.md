# OBSIDIAN — сайт детейлинг-студии (React + Tailwind CSS + Lucide)

Демонстрационный frontend-проект. Backend, базы данных и внешние API не используются:
вся логика (каталог, фильтры, онлайн-запись, формы, уведомления) работает на React useState.

## Кинематографичное интро
Первый экран — 4 сцены с видео-переходами (Higgsfield + Kling 3.0), один жест скролла = один переход.
Подробно о процессе, промптах и замене роликов — в PROCESS.md.
Видео лежат в public/media, поэтому сайт собирается в папку dist/ (не в один файл).

## Запуск
    npm install
    npm run dev          # http://localhost:5173
    npm run build        # продакшн-сборка в dist/
    python3 scripts/test-intro.py   # автотест механики интро (нужен запущенный сервер на :4173)

## Структура
    src/
      data.js                  ← ВСЕ тексты, услуги, цены, мастера, отзывы, контакты, фото
      App.jsx                  ← сборка страницы, состояние записи и уведомлений
      index.css                ← тема Tailwind: цвета, шрифты, анимации, кнопки
      components/
        Header.jsx             ← шапка, активный раздел, мобильное меню
        Advantages.jsx         ← цифры и преимущества сразу после интро
      intro/
        CinematicIntro.jsx     ← сцены, видео-переходы, обработка скролла/свайпов/клавиш
        config.js              ← скорость роликов, пауза жеста, таймауты, список файлов
        Services.jsx           ← каталог с фильтром по категориям
        About.jsx              ← о студии, коллаж, слайдер «до/после», мастера
        Reviews.jsx            ← отзывы (на телефоне — свайп-карусель)
        Contacts.jsx           ← контакты, карта-иллюстрация, обратный звонок, подвал
        BookingModal.jsx       ← онлайн-запись: услуга → мастер → дата/время → данные → успех
        ui.jsx                 ← изображения с fallback, анимации появления, звёзды, тосты, маска телефона

## Как адаптировать под другой бизнес
Меняйте только src/data.js: BRAND (контакты), SERVICES, MASTERS, REVIEWS, SLOT_HOURS.
Цвета — в блоке @theme в src/index.css (--color-gold — акцент).

## Фото
Все фото сгенерированы в Higgsfield (GPT Image 2.6) в стиле бренда и лежат в public/photos в формате WebP:
услуги (svc-*.webp), коллаж «О студии» (about-*.webp), слайдер «до/после» (before/after.webp), мастера (master-*.webp).
Внешних картинок нет — сайт целиком работает офлайн. Для реального бизнеса замените их фото своих работ и команды
с теми же именами файлов. Промпты — в PROCESS.md.

## Онлайн-запись (демо)
- Занятые слоты генерируются детерминированно по дате и мастеру (~20–38% занято, ~10% дней полностью заняты)
- Прошедшие даты и прошедшее время сегодня недоступны
- Запись открыта на 3 месяца вперёд
- Для реальной записи подключите YCLIENTS / Altegio / свой API в функции next() в BookingModal.jsx
